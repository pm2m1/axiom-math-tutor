# data/

Provenance manifests and evaluation data for Axiom's knowledge base. This
directory holds small, deterministic, checked-in files — not downloaded
web pages. Raw fetched HTML lives under `.data/raw/` (git-ignored) and is
regenerated by the ingestion command, not committed.

```text
data/
├── manifests/
│   └── algebra_sources.json   Source pages: URL, license, attribution, topic
├── corpus/
│   └── algebra_chunks.jsonl   Normalized, chunked KB content (generated)
└── evaluation/
    └── algebra_retrieval.jsonl  Labeled retrieval queries (hand-checked)
```

## Corpus

The current knowledge base is a narrow algebra slice: equations and their
properties, inequalities (including absolute value), and quadratic equations
(completing the square, the quadratic formula, the discriminant). It is
sourced entirely from [Wikibooks: Algebra](https://en.wikibooks.org/wiki/Algebra),
licensed CC BY-SA 4.0. See `manifests/algebra_sources.json` for the exact
pages, retrieval date, and per-page attribution.

Topics explicitly considered and left out because no page in this source
covers them cleanly: the distributive property and general factoring (the
one candidate page, `Algebra/Chapter_2/Arithmetic`, renders with all six of
its section headings collapsed together with no content between them — a
quirk of that page's markup, not something worth working around by guessing
where the content belongs), zero-product property, solving quadratics by
factoring, and absolute-value equations as distinct from absolute-value
inequalities. These are gaps in the current corpus, not missing features.

Regenerate the corpus with:

```bash
cd apps/api
uv run python -m axiom.knowledge.ingest
```

This fetches each manifest URL (cached under `.data/raw/`, pass `--refresh`
to bypass the cache), chunks it, and overwrites `corpus/algebra_chunks.jsonl`.
Chunk IDs are `{document_id}-{index:02d}` and are stable as long as the
source page's heading structure doesn't change.

## Evaluation set

`evaluation/algebra_retrieval.jsonl` has 50 labeled queries (42 in-scope, 8
out-of-scope) against the current corpus. Every `relevant_chunk_ids` entry
was checked by reading the actual chunk text, not generated and assumed
correct — see `docs/retrieval-evaluation.md` for the labeling process and
the measured baseline.
